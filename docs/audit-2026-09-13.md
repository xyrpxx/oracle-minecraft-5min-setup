## 2. Findings fixed this session (P0)

1. Missing `sudo` on privileged remote blocks — `uninstall.sh`, `security/hardening.sh`
   (+ missing `apt-get update`), `utils/backup.sh`, `utils/restore.sh`; `utils/monitor.sh`
   now runs with sudo so RCON sections work. `uninstall.sh` also removes
   keepalive/auto-sleep/discord units and uses `set -euo pipefail`.
2. `utils/backup.sh` crashed with zero args under `set -u` → `case "${1:-}"`.
3. `utils/console.sh` remote injection (`$`, backticks, `\` executed as root) →
   command travels base64 as positional arg; same pattern applied to
   `security/whitelist_manager.sh` (plus `|| true` on the white-list grep).
4. `utils/mods.sh`: remote `${VERSION}` unbound under `set -u` → passed as arg;
   `.mrpack` path traversal (`../` → arbitrary root write) → relative-path
   allowlist with rejection.
5. `security/keepalive.sh`: 4 workers (up to 400% CPU) → single worker (~25%),
   plus `set -euo pipefail`, validated ON/OFF_MIN, systemd doc with
   Nice/CPUWeight/CPUQuota/MemoryMax, mutual-exclusion warning with auto-sleep.
6. `utils/restore.sh`: `for entry in $map_to_remove` (split+glob on tar listing)
   → line-wise loop, globbing off, rejects absolute/`..`/non-simple names.

## Addendum 2026-09-13 (Round 3 — target 9.1/10, harsh rating, no cheating)

Round 2 closed at 8.0/10. The honest gaps to 9.1 were: (1) manage.sh
French-only despite the plan's i18n mandate, (2) auto-sleep measuring service
uptime instead of true player-idle time, (3) no jar checksums on the
Mojang/Forge/Fabric path, (4) hygiene blockers (`.zcode/` scratch, stale
`370+` counts), (5) README underselling the new menu-9 installers.

### Fixed

- **Bilingual manage.sh** — all visible strings via `scripts/lang_*.sh`
  (`M_MENU_*`, `M_OCI_*`, `M_CRAFTY_*` catalogs, ~50 keys × 2 languages),
  auto-detection + `--lang` override like setup.sh. Verified rendering in
  both languages (menu + OCI submenu); 14 new test assertions.
- **True-idle auto-sleep** — `/opt/minecraft/.state/empty_since` marker:
  stop only after IDLE_MINUTES with zero players; marker cleared on any
  player presence, on service stop, and after stopping. Reboots no longer
  fake idle time; players leaving 1 min ago no longer trigger a stop.
  Fail-closed on non-numeric IDLE_MINUTES.
- **Verified downloads** — `download_verified` helper: vanilla strict
  fail-closed on Mojang's published `downloads.server.sha1`; Forge via live
  Maven `.sha1` sidecar (verified reachable); Fabric honest WARN (no upstream
  hash) + non-empty enforcement everywhere.
- **Hygiene** — `.zcode/` gitignored (session scratch never committed);
  secret scan clean (only doc-example IPs); README counts updated to 485.
- **README maximization (EN+FR)** — v3.7 block lists menu-9 paths for every
